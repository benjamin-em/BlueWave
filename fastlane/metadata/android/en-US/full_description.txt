<b>BlueWave</b> is an ad-free, tracking-free, paywall-free car radio app. It is a personal fork of AMARadio with a blue redesign, location-based Home groups (city / province / national / English stations), automatic car mode over Bluetooth, and steering-wheel station switching.

<b>Key Features</b>
- 60,000 stations via Radio-Browser API
- Local Radio-Browser database
- Optional background sync with Radio-Browser database
- Android Auto Integration
- Modern Home Screen Widgets
- Custom Radio Stations
- Advanced Search & Filtering: Find stations by Name, Country, Language, or Tags.
- Dynamic UI Scaling
- Broad Language Support
- Modern Design: Jetpack Compose, Dark/Light modes.
- Optimized Image Loading via Coil
- Sleep timer, favorites management, custom station management, and M3U export/import.
